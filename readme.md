## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/beetstack-website.git
```

### 2. Install dependencies

```bash
pnpm install
```

### 3. Run development server

```bash
pnpm dev
```

### 4. Build for production

```bash
pnpm build
```
